# node_fills_by_block

Cleaning scripts:

- `scripts/data_cleaning/node_fills.py`
- `scripts/data_cleaning/parquet_cache.py`

Official references:

- Historical data: https://hyperliquid.gitbook.io/hyperliquid-docs/historical-data
- Info endpoint: https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint

## Raw Fields

| Field | Type | Source | Status | Meaning |
|---|---|---|---|---|
| `local_time` | string timestamp | S3 wrapper | `s3_header` | Time when the S3 record was locally archived or written by the source wrapper. |
| `block_time` | string timestamp | S3 wrapper | `s3_header` | Timestamp string for the block. |
| `block_number` | integer | S3 wrapper | `s3_header` | Block number. |
| `events` | array | S3 wrapper | `s3_header` | Fill event array within the current block. |
| `events[][0]` | string | S3 wrapper | `observed` | User address associated with the fill. |
| `events[][1]` | object | fill payload | `official` | Fill payload matching the user fill structure. |
| `coin` | string | fill payload | `official` | Market symbol. |
| `px` | string/number | fill payload | `official` | Execution price. |
| `sz` | string/number | fill payload | `official` | Execution size. |
| `side` | string | fill payload | `official` | Execution side field. |
| `time` | integer ms | fill payload | `official` | Execution time as a millisecond Unix timestamp. |
| `startPosition` | string/number | fill payload | `official` | Position before the fill. |
| `dir` | string | fill payload | `official` | Fill category, such as open, close, liquidation, or ADL. |
| `closedPnl` | string/number | fill payload | `official` | PnL generated by the closed portion of this fill. |
| `hash` | string | fill payload | `official` | Transaction hash. |
| `oid` | integer | fill payload | `official` | Order id. |
| `crossed` | boolean | fill payload | `official` | Whether the order crossed the book. |
| `fee` | string/number | fill payload | `official` | Fee. |
| `tid` | integer | fill payload | `official` | Trade id. |
| `cloid` | string/null | fill payload | `official` | Client order id. |
| `feeToken` | string | fill payload | `official` | Fee-denomination token. |
| `twapId` | integer/null | fill payload | `official` | TWAP id. |
| `builderFee` | string/number/null | fill payload | `observed` | Builder fee field observed in the sample. |
| `builder` | string/null | fill payload | `observed` | Builder address field observed in the sample. |
| `liquidation` | object/null | fill payload | `observed` | Nested object related to liquidation. |
| `liquidation.liquidatedUser` | string/null | `liquidation` | `observed` | Liquidated user provided directly in the S3 payload. |
| `liquidation.markPx` | string/number/null | `liquidation` | `observed` | Liquidation mark price provided in the S3 payload. |
| `liquidation.method` | string/null | `liquidation` | `observed` | Liquidation method provided in the S3 payload. |
